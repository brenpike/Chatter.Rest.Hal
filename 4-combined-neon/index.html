Everything you need to speak HAL in .NET.

    

      
01
Fluent builder
Chain AddSelf, AddLink and AddEmbedded. Stage-typed, so the shape stays valid.


ResourceBuilder
  .WithState(new { id = 7 })
  .AddSelf()
  .AddLinkObject("/orders/7")
  .Build();

      
02
Typed deserialization
Read into your own DTOs. [HalResponse] generates _links and _embedded.


[HalResponse]
public partial class Order
{
    public int Id { get; set; }
}

      
03
Stable link arrays
One link or many, clients get one shape. Opt in globally or per relation.


HalJsonOptions.Default
  .AlwaysUseArrayForLinks = true;
// "next": [{ "href": "/o?p=2" }]

      
04
RFC 6570 URI templates
Levels 1 to 3. Expand a templated link straight from its link object.


link.Expand(
  ("q", "dotnet"),
  ("lang", "en"));
// /search?q=dotnet&lang=en
